FOTOS DO SITE
=============

Para trocar uma foto, envie outra com EXATAMENTE o mesmo nome para esta pasta (img).
Se uma foto não existir, o site mostra um bloco cinza com a descrição.

Dicas:
- Use fotos .jpg com até ~300 KB cada (dá para reduzir em squoosh.app ou tinypng.com).
- Ao trocar uma foto de projeto, atualize no index.html o texto "alt" dela,
  descrevendo o ambiente (ajuda no Google).
